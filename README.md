## Rocky modules

**Rocky modules** are pieces of code that are built using the **Solver SDK** to apply novel models, laws or functionalities to Rocky simulations. By using your own custom modules, you can add specific features for your simulations at your own time.
Here you can find all the example modules previously downloaded on Ansys Customer Portal.

### Available example modules

1. Air Knife Actuator Sensor;
2. Compression Motion;
3. Contact Curves;
4. Field Force Example;
5. Geometry Actuator Sensor;
6. Motion Frame;
7. SPH LES Model;
8. SPH Spray Nozzle;
9. Spherical Region;
10. Transient Adhesive Force;
11. Transient Size Scale.

**The modules are created using the Solver SDK tool:**

https://developer.ansys.com/docs/rocky-solver-sdk-2026-r1/index.md
